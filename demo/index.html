react-tostack

Toasts for React that grow out of the top of the screen like the iOS Dynamic Island, and change shape to fit each message.

GitHub

Quick start

  1. Install: npm i react-tostack
  2. Add <Toaster /> once near the root of your app.
  3. Call toast('Hello') anywhere.

Features

  • Dynamic Island mode that morphs one toast in place, or stacked toasts in six positions
  • Spring physics, up to three toasts at once with a queue, hover to see all
  • Close button, optional swipe to dismiss, Escape to close, expandable details and actions
  • Promise, loading, success, error, warning, info and custom JSX toasts
  • Light, dark and system themes, glass or solid surface, TypeScript types included
