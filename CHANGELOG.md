# Changelog

## 0.1.1

Smaller package, same behaviour.

- The package download is 63% smaller (80 kB to 30 kB) and takes 67% less space once installed. Source maps are no longer shipped.
- The bundled stylesheet is minified, and the build targets ES2020, so the JavaScript is about 10% smaller.
- Uses the automatic JSX runtime (`react/jsx-runtime`).
